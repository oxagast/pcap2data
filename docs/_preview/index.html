PacketSnitch Feature List

PacketSnitch is a full-featured network packet analysis tool with a Python backend for deep protocol parsing and an Electron desktop frontend for interactive browsing, filtering, and forensic investigation. This document lists all available features.

Protocol Decoders (Backend)

The backend extracts rich, queryable metadata for the following protocols:

Concise decoder list:

  • Link/WAN: Ethernet, ATM, Token Ring, Frame Relay, SDLC, HDLC, SLIP, PPP (LCP/NCP/LAP), ARP, RARP
  • Network: IPv4, ICMP, IGMP
  • Transport: TCP, UDP, SCTP
  • Application: HTTP/1.x, HTTP/2, HTTPS, DNS, SNMP, DHCP, NTP, FTP, SMTP, POP3, IMAP, Telnet, IRC, SIP, SMB, MQTT, RTSP, TFTP, BGP, XMPP, LDAP, MySQL, PostgreSQL, NNTP, MTP/MMS, RADIUS, WebSocket, NFS, Kerberos, SSH/OpenSSH, SMPP, Soulseek, BitTorrent

Host Data View

The Host Data View provides a comprehensive overview of all hosts detected in the capture, including their IP addresses, MAC addresses, hostname resolution, geographic location, and communication patterns.

Payload Analysis

Deep payload inspection for extracting credentials, file transfers, and other sensitive data from protocol streams. Supports regex-based pattern matching and heuristic detection.

TCP Stream Analysis

Reassemble and analyze TCP streams with full payload reconstruction, timing analysis, and anomaly detection.

Link-Layer & Non-IP Protocol Support

Full support for non-IP protocols including Ethernet, 802.11, Bluetooth, and other link-layer protocols commonly found in enterprise environments.

Filter Engine

Powerful BPF-compatible filter engine with support for complex expressions, saved filters, and real-time filter preview.

Capture Loading

Support for PCAP, PCAPNG, and live capture interfaces. Automatic detection of capture format with seamless loading.

Packet Navigation

Quick navigation between packets with keyboard shortcuts, jump-to-packet, and bookmark support.

Session Management

Save and restore analysis sessions including all views, filters, and annotations. Export sessions for sharing or archival.

Settings Workspace

Comprehensive settings for customizing PacketSnitch behavior, appearance, and analysis options.

Theme Engine

Customizable themes with support for dark and light modes. Create and share custom themes with the community.

Plugin Engine

Extensible plugin architecture allowing third-party developers to add new protocol decoders, analysis tools, and UI components.

Statistics Tab

Comprehensive traffic statistics including protocol distribution, conversation matrices, and time-series charts.

List Tab

Detailed packet list with sortable columns, filtering, and color-coding for quick analysis.

Conv Tab (Data Conversion Workspace)

Convert captured data between formats including hex, base64, URL encoding, and more.

Crypt Tab (Encryption Workspace)

Decrypt and analyze encrypted traffic with support for TLS, SSL, and other encryption protocols.

Keystore Tab (Local Credential Store)

Secure local storage for credentials, keys, and certificates used in analysis.

Notes Tab (Session Notes)

Take notes during analysis with support for rich text, timestamps, and packet references.

Activity Log Tab

Track all analysis activities with a comprehensive activity log for audit and review purposes.

Context Menu (Right-Click)

Context-sensitive right-click menus throughout the application for quick access to common actions.

LLM-Powered Analysis (Ollama)

Integration with Ollama for AI-powered analysis including natural language queries, anomaly detection, and automated reporting.

Backend HTTP Service / Bridge

HTTP service interface for integrating PacketSnitch with external tools and scripts.

GeoIP Enrichment

Automatic geographic location enrichment for IP addresses with support for MaxMind and IP2Location databases.

Active Reconnaissance (Optional)

Optional active reconnaissance capabilities for authorized penetration testing and security assessments.

Backend CLI

Command-line interface for scripting and automation of common analysis tasks.

Backend Output

Multiple output formats including JSON, CSV, and custom formats for integration with other tools.

Session Keystore Export

Export session keystores for backup or transfer to other installations.

Packaging & Distribution

Native packages for Debian, Ubuntu, Fedora, CentOS, and Windows with automatic updates.

PacketSnitch provides comprehensive network analysis capabilities with a focus on usability and extensibility. The tool is designed for security professionals, developers, and researchers who need to analyze packet captures quickly and efficiently.

The Python backend handles all the heavy lifting of protocol parsing and data extraction, while the Electron frontend provides a modern, responsive user interface for interactive analysis. This separation allows the backend to be used independently for scripted analysis or integration with other tools.

Whether you're investigating a security incident, troubleshooting network issues, or researching protocol behavior, PacketSnitch provides the tools you need to get the job done. The extensible plugin architecture allows you to add custom decoders and analysis tools as needed.
