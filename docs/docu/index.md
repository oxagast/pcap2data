# Documentation

Welcome to the PacketSnitch documentation. Use the links below to dive into each area of the project.

## Reference

- [**Backend Documentation**](backend) — Python backend (`snitch.py`) plus the Electron bridge HTTP service mode: usage, arguments, output structure, transport modes, and searchable attributes.
- [**Frontend Documentation**](frontend) — Electron frontend: UI workspaces, worldmap/heatmap, PGP tooling, settings, LLM flows, and bridge controls.
- [**Plugins Documentation**](plugins) — Combined Themes + Plugins reference: theme engine schema plus complete plugin engine tutorial and hello-snitch sample code.
- [**Filter Reference**](filters) — Complete guide to the filter bar: all filter keys, search syntax, operators, boolean combinators, and examples.
- [**Context Menu Reference**](context-menu) — Right-click context menu: copy, convert, filter, keystore, notes, and export options.
