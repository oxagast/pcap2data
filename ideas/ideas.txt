# PacketSnitch Proposed Prioritized Release Plan

Date: 2026-06-15
Complexity scale:
- Low: Small feature, mostly UI/state or simple backend wiring
- Medium: Cross-module work, moderate parser/data changes
- High: Stateful analysis, new panels, or significant backend logic
- Very High: Architecture-level changes (plugins/live capture)

Assumptions for estimates:
- Estimates are engineering implementation time only (single developer).
- Add 20-35% for QA, bug-fixing, and release packaging.
- 1 week ~= 5 dev days.

## Release 0.9.0 (Quick Wins, 3-5 weeks)
Goal: Increase daily analyst usability with low risk and short delivery cycle.

1) Saved Filter Library (named filters + tags)
- Priority: P0
- Complexity: Low
- Est. dev time: 2-3 days
- Dependencies: None

2) Rule-based Highlights (color rows/cards by filter match)
- Priority: P0
- Complexity: Low
- Est. dev time: 2-4 days
- Dependencies: Reuse filter evaluator

3) Packet Pinboard (collect suspicious packets across hosts)
- Priority: P1
- Complexity: Low
- Est. dev time: 1-2 days
- Dependencies: None

4) IOC Extraction Panel (IP/domain/URL/hash/email extraction + dedupe)
- Priority: P0
- Complexity: Medium
- Est. dev time: 4-6 days
- Dependencies: None

5) One-click IOC Export (CSV + JSON)
- Priority: P0
- Complexity: Low
- Est. dev time: 1-2 days
- Dependencies: IOC Extraction Panel

6) Report Templates (IR summary + triage report export)
- Priority: P1
- Complexity: Low
- Est. dev time: 2-3 days
- Dependencies: None

Release 0.9.0 total estimate: 12-20 dev days

## Release 0.10.0 (Analyst Depth, 4-7 weeks)
Goal: Add stronger investigative pivots and behavioral insights.

1) Diff Two Packets (field-by-field compare)
- Priority: P0
- Complexity: Medium
- Est. dev time: 3-5 days
- Dependencies: None

2) Filter Builder UI (visual query builder with boolean groups)
- Priority: P1
- Complexity: Medium
- Est. dev time: 4-7 days
- Dependencies: Stable filter grammar/parser

3) DNS Threat Lens (entropy outliers, rare TLDs, NXDOMAIN spikes)
- Priority: P0
- Complexity: Medium
- Est. dev time: 4-6 days
- Dependencies: Stats aggregation hooks

4) Protocol Anomaly Heuristics (packet/session suspicion score)
- Priority: P0
- Complexity: Medium
- Est. dev time: 5-8 days
- Dependencies: Shared rule engine preferred

5) Batch Analysis (multi-file ingest + consolidated session summary)
- Priority: P1
- Complexity: Medium
- Est. dev time: 4-6 days
- Dependencies: Job orchestration and session merge model

6) Case Workspace (notes linked to packets/IOCs)
- Priority: P1
- Complexity: Medium
- Est. dev time: 4-7 days
- Dependencies: IOC entity model; session persistence

Release 0.10.0 total estimate: 24-39 dev days

## Release 0.11.0 (Advanced Forensics, 6-10 weeks)
Goal: Bring deeper network-forensics capability closer to mature analyzers.

1) Expert Events Feed (anomaly/event stream with severity)
- Priority: P0
- Complexity: High
- Est. dev time: 8-12 days
- Dependencies: Protocol anomaly heuristics foundation

2) TLS Fingerprinting (JA3/JA4-like summaries)
- Priority: P1
- Complexity: Medium
- Est. dev time: 3-5 days
- Dependencies: TLS parser enrichment

3) Stream Reassembly (TCP payload reassembly for readable streams)
- Priority: P0
- Complexity: High
- Est. dev time: 10-16 days
- Dependencies: Reliable stream keying and ordering

4) HTTP Object Extraction (responses/files from reassembled streams)
- Priority: P0
- Complexity: High
- Est. dev time: 8-14 days
- Dependencies: Stream Reassembly

5) Timeline View (zoomable event timeline)
- Priority: P1
- Complexity: High
- Est. dev time: 6-10 days
- Dependencies: Event model and cached aggregations

6) Conversation Graph (host/service interactive graph)
- Priority: P2
- Complexity: High
- Est. dev time: 6-10 days
- Dependencies: Conversation aggregation model

Release 0.11.0 total estimate: 41-67 dev days

## Long-term (1.0+)
Goal: Platform-level extensibility and live operations.

1) Alert Rules + Notifications (saved detections over ingest)
- Priority: P1
- Complexity: Medium
- Est. dev time: 4-7 days
- Dependencies: Rule engine + event bus

2) Redaction Profiles (mask secrets in UI/export)
- Priority: P1
- Complexity: Medium
- Est. dev time: 3-5 days
- Dependencies: Export pipeline integration

3) Local Plugin API (custom decoders)
- Priority: P2
- Complexity: Very High
- Est. dev time: 20-35 days
- Dependencies: Stable extension contract and sandboxing

4) Mini Decoder Scripting (user script runtime)
- Priority: P3
- Complexity: Very High
- Est. dev time: 18-30 days
- Dependencies: Plugin API and security controls

5) Live Capture Mode (interface select + rolling ingest)
- Priority: P2
- Complexity: Very High
- Est. dev time: 20-40 days
- Dependencies: Capture orchestration, buffering, UX for long-running jobs
